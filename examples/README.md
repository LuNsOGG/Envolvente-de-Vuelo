# Proyectos de ejemplo

El menú **Ejemplos** ofrece **Ejemplo Cessna** y **Ejemplo libro**. También pueden abrirse estos JSON con **Abrir**.

| Archivo | Contenido |
|---|---|
| [ejemplo_cessna.json](ejemplo_cessna.json) | Predeterminado: ficha revisada de 4000 lb y comparación de 4631 lb del capítulo 1.9 de la tesis IPN |
| [ejemplo_libro.json](ejemplo_libro.json) | Caso comercial de Niu con tabla aerodinámica por Mach |
| [ejemplo_1.json](ejemplo_1.json) | Histórico del Excel de la tesis, anterior a la revisión de pesos, polar y cuerda |
| [ejemplo_2.json](ejemplo_2.json) | Histórico del libro con nombre numerado; resultados conservados |

Los archivos numerados se conservan para reproducir entregas anteriores. Cada proyecto mantiene unidades, procedencia y supuestos. Los archivos actuales se abren sin necesitar los escaneos originales. El Cessna requiere revisar las hipótesis de pendiente, ráfagas y polar 2D descritas en [la revisión de la tesis](../docs/cessna_tesis_20261024/README.md).
