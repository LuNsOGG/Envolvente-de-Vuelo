# Proyectos de ejemplo

Abra estos archivos desde la aplicación con **Abrir**, o use el menú **Ejemplos** para generar casos equivalentes.

| Archivo | Contenido |
|---|---|
| `ejemplo_1.json` | Hoja Excel con hipótesis explícitas de CN− y ráfagas |
| `ejemplo_2.json` | Ejemplo comercial de Niu con tabla por Mach |

Cada archivo mantiene unidades, procedencia, valores originales y supuestos. Los IDs y fechas de estos archivos son los de su creación; el menú puede generar identificadores nuevos sin cambiar la condición física. Para otra aeronave introduzca sus propios datos y revise el modelo aerodinámico seleccionado.
